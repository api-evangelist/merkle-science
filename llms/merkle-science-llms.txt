# Merkle Science

> Merkle Science is a blockchain analytics and predictive crypto risk platform for AML/KYC/CFT compliance, investigation, and due diligence across 10,000+ crypto assets. This llms.txt is generated by API Evangelist from the public KYBB API surface and the API Evangelist catalog.

## APIs
- [KYBB API Reference](https://kybb.docs.merklescience.com/reference/introduction): Know Your Blockchain Business — off-chain VASP due-diligence data (KYC/AML posture, supported coins, permitted activities, regulatory alerts, licensing, legal entities, restrictions).
- [Authentication](https://kybb.docs.merklescience.com/reference/authentication): x-api-key header over HTTPS; keys issued directly by Merkle Science. Sandbox host api.kybb.dev.merklescience.com, production host api.kybb.app.merklescience.com.
- [Pagination](https://kybb.docs.merklescience.com/reference/pagination): offset/limit paging; responses carry count, next, previous, results.
